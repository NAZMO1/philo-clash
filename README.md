# PhiloClash

Un quiz web interactif et chronométré qui confronte citations de grands philosophes, punchlines de rap et répliques cultes de films, avec une micro-fiche pédagogique après chaque réponse.

## Fonctionnalités
- Chronomètre dynamique de 12 secondes
- Révélation immédiate du contexte et de la leçon philosophique
- Données structurées en JSON (générées via Google AI Studio / Gemini)
- Design mobile-first avec Tailwind CSS

## Lancer le projet en local
1. Cloner le dépôt : `git clone https://github.com/TON_PSEUDO/philo-clash.git`
2. Ouvrir le dossier : `cd philo-clash`
3. Lancer un serveur local : `npx serve` ou `python3 -m http.server`
